# After Dark

A quiet alternate web space for late-night notes, links, logs, and unfinished ideas.

## Local preview

```sh
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Structure

- `index.html` contains the page markup and URL directory.
- `styles.css` handles the layout and visual system.
- `script.js` renders the pixel-art background on canvas.
- `.github/workflows/pages.yml` publishes the site to GitHub Pages.
